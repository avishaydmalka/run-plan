# תוכנית ריצה – חצי מרתון תל אביב 2027 🏃

אפליקציית ווב (קובץ HTML אחד) לתוכנית אימונים של 15 שבועות לחצי מרתון תל אביב, שנערך ב-26.2.2027.

## מה יש באפליקציה
- **היום**: האימון של מחר, האימון של היום ופס התקדמות שבועי.
- **לוח שנה**: לחיצה על יום מציגה את האימון המלא, ואפשר לסמן אותו כבוצע עם מרחק בפועל והערה.
- **שבועות**: נפח מתוכנן מול מה שבוצע בכל אחד מ-15 השבועות.
- **שאל**: צ'אט עם Gemini שמכיר את התוכנית, את הספים שלך ואת הדיווחים שלך.

## התאמה אישית
בכניסה הראשונה כל משתמש בוחר אחת מהאפשרויות:
1. **להזין ספים**: זמן ל-5 ק"מ, 10 ק"מ או חצי מרתון, וממה הוא לקוח (תחרות, טסט או **הערכה**). אפשר להוסיף דופק ממוצע בריצה, דופק מנוחה ודופק מקסימלי.
   - כל הקצבים בתוכנית מחושבים מחדש ביחס לזמן השקול ל-10 ק"מ (לפי נוסחת Riegel).
   - דופק הסף נלקח מהדופק הממוצע בריצה, ואם הוא לא הוזן, מוערך מהדופק המקסימלי. טווח הדופק לריצה קלה מחושב מדופק המנוחה ודופק הסף.
   - כשהזמן מסומן כהערכה, הקצבים איטיים ב-3% עד שנעשה טסט אמיתי.
2. **לדלג**: כל האימונים יוצגו לפי תחושת מאמץ, למשל "שיחה חופשית" או "קצב 10 ק"מ".

את הספים אפשר לשנות בכל שלב בהגדרות, ובמיוחד כדאי לעדכן אותם אחרי טסט ה-10 ק"מ ב-11.12.2026.

## מפתח Gemini (חינמי)
1. היכנסו ל-https://aistudio.google.com/apikey עם חשבון Google.
2. לחצו **Create API key**.
3. הדביקו את המפתח בהגדרות האפליקציה.

המפתח נשמר רק בדפדפן של המשתמש ונשלח רק ל-Google. המסלול החינמי מוגבל במספר הבקשות.

## פרטיות
אין שרת. כל הנתונים (ספים, דיווחים ומפתח) נשמרים ב-localStorage של כל משתמש בנפרד. בהגדרות יש גיבוי ושחזור להעברה בין מכשירים.

## פרסום ב-GitHub Pages
Settings ← Pages ← Source: **Deploy from a branch** ← `main` / `root` ← Save.
אחרי כדקה האתר יהיה זמין בכתובת `https://<user>.github.io/run-plan/`.

## עדכון התוכנית
- `tools/gen_plan.py` מייצר את `plan/plan.json` ואת קובצי ה-CSV.
- `tools/build.py` בונה את `index.html` מתוך `tools/template.html` והתוכנית.

```bash
python3 tools/gen_plan.py && python3 tools/build.py
```

> התוכנית מבוססת על תבנית של מאמן והורחבה ל-15 שבועות. היא לא מחליפה ליווי מקצועי.
