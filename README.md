# תוכנית ריצה – חצי מרתון תל אביב 2027 🏃

אפליקציית ווב לתוכנית אימונים של 15 שבועות לחצי מרתון תל אביב (26.2.2027). האפליקציה רצה על **Cloudflare Workers** עם מסד נתונים **D1**.

## מה יש
- **לרצים** (`/`):
  - **האימון של מחר**: מותאם לספים האישיים של כל רץ.
  - **לוח שנה**: עם דיווח מרחק בפועל והערות.
  - **מבט שבועי**.
  - **צ'אט עם Gemini**: מכיר את התוכנית ואת הנתונים של הרץ.
- **למאמן** (`/coach`, בסיסמה): כל הרצים, ספים, ביצוע שבועי, אחוז ביצוע והערות אחרונות.

## איך זה עובד
| | |
|---|---|
| זהות | כל רץ מקבל **קוד אישי** (למשל `ABCD-2345`). עם הקוד נכנסים מכל מכשיר, בלי סיסמה. |
| ספים | זמן ל-5 ק"מ, 10 ק"מ או חצי מרתון, מתחרות, טסט או **הערכה**. אפשר להוסיף דופק ממוצע, דופק מנוחה ודופק מקסימלי. כל הקצבים והדפקים מחושבים לפיהם. בהערכה הקצבים איטיים ב-3%. אפשר גם לדלג ולהתאמן לפי תחושה. |
| צ'אט | ברירת המחדל היא **המפתח המשותף** שנשמר בשרת, עם מכסה יומית לכל רץ ומכסה כללית. רץ יכול להזין מפתח Gemini אישי, ואז הבקשות הולכות ישירות מהדפדפן שלו ל-Google. |
| נתונים | טבלת `users` ב-D1 (קוד, שם, ספים, דיווחים), עם עותק מקומי בדפדפן. |

## מבנה
```
wrangler.toml          הגדרות ה-Worker, D1 ומגבלות
src/worker.js          ה-API: /api/user, /api/chat, /api/coach, /api/health
public/index.html      האפליקציה (נבנית מ-tools/template.html)
public/coach.html      מסך המאמן (נבנה מ-tools/coach_template.html)
plan/                  התוכנית: JSON ו-CSV
tools/gen_plan.py      יוצר את plan/plan.json
tools/build.py         בונה את public/ מהתבניות ומהתוכנית
```

## פריסה (פעם אחת)
1. ב-Cloudflare: **Workers & Pages** ← **Create application** ← **Import a repository** ← בחר את `run-plan`.
   - שם ה-Worker: `run-plan`. הוא חייב להיות זהה ל-`name` ב-`wrangler.toml`.
   - Build command: ריק. Deploy command: `npx wrangler deploy`. ← **Deploy**.
2. ב-Worker: **Settings** ← **Variables and Secrets** ← **Add**, מסוג **Secret**:
   - `GEMINI_API_KEY`: מפתח מ-https://aistudio.google.com/apikey.
   - `COACH_PASSWORD`: סיסמה למסך המאמן.
   - `INVITE_CODE` (אופציונלי): קוד שרצים חדשים יצטרכו להזין, כדי שזרים לא ישתמשו במפתח שלך.
3. מסד הנתונים `run-plan-db` כבר קיים, והטבלאות נוצרות אוטומטית.

מאותו רגע כל push ל-`main` מתפרס אוטומטית.

## מגבלות (ב-`wrangler.toml`)
- `DAILY_LIMIT`: שאלות ביום לכל רץ על המפתח המשותף. ברירת מחדל: 40.
- `GLOBAL_DAILY_LIMIT`: שאלות ביום לכל הרצים יחד. ברירת מחדל: 1000.
- `GEMINI_MODEL`: ברירת מחדל `gemini-flash-latest`. אם המודל לא קיים, השרת עובר למודל הבא ברשימה.

## עדכון התוכנית
```bash
python3 tools/gen_plan.py && python3 tools/build.py
```

> התוכנית מבוססת על תבנית של מאמן והורחבה ל-15 שבועות. היא לא מחליפה ליווי מקצועי.
